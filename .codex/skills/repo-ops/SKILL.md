# Skill: repo-ops

Purpose:
Run deterministic repository validation checks.

When to use:
- Before merge to `main`.
- After changing APIs, parser, renderer, or CI/governance files.

Steps:
1) Run tests:
   `swift test`
2) Run FCIS structure check:
   `bash Scripts/fcis-check`

Output contract:
- Report commands run and pass/fail status.
- List changed files generated by commands (if any).
